## 随包词库

基础词库 8.7 万条，另有 11 本领域词库随包：法律、医学、地名、成语、诗词名句、IT、财经、饮食、动物、汽车、历史人物。
缺省只开启成语，其余在「偏好设置 → 词库」勾选。领域词库只影响「是否有这个词」，不改变整句转换的权重。

## 导入用户词库

「偏好设置 → 词库 → 导入词库…」，接受三种格式：

- 青简 TSV：每行 `词<Tab>拼音<Tab>词频`，拼音音节间以空格分隔。
- Rime 的 `.dict.yaml`：读取名称和文件内的词条，词条须为 `词<Tab>拼音[<Tab>权重]`，拼音音节间以空格分隔，非整数权重按 1 处理。不支持 `import_tables` 引用的其他词库、自定义 `columns` 列顺序或 `.schema.yaml` 方案配置。
- 青简 `.qj`：他人制作的词库文件，自带名称与许可证。

TSV 与 Rime 词库导入时，`lue` / `nue` 自动统一为 `lve` / `nve`。词库用 `v` 表示 ü。
旧词库里写成 `lue` / `nue` 的词也照常能打。

导入后列在随包词库之下，显示名称、条数、许可证。可单独开关；「移除」只将文件移到一旁，不删除。

Windows 导入时会转换成 `.qj` 并自动启用，设置页显示导入条数或失败原因。没有可用词条的文件不能导入。
文件选择窗口支持按 Ctrl 或 Shift 多选，批量导入 YAML、TSV 或 `.qj`；单个文件失败不影响其余文件，完成后显示成功、失败数量及各文件结果。
输入法运行时通常在约一秒内自动加载；同名重新导入和移除也会自动更新，无需重启。
若手动编辑配置时出现格式错误，词库仍按上次有效的开关设置加载；修正配置后自动恢复应用新设置。
Rime 文件要经「导入词库…」转换，直接放进词库目录不会加载。

## 自动更新（词库页里勾「自动更新」）

几本社区长期维护的词库可以直接在**偏好设置 → 词库**里勾「**自动更新**」，青简会定期去上游
release 看有没有新版，有就自动下载 + 导入（覆盖同名 `.qj`）：

| 词库 | 内容 |
| --- | --- |
| `zhwiki` | 维基百科词频表（百万级，常词底表） |
| `web-slang` | 网络流行语 |
| `zhwiktionary` | 维基词典条目 |
| `zhwikisource` | 维基文库（古籍 / 文献词汇） |

上游是 fcitx5-pinyin-zhwiki 的 release；页面上的「**自动更新周期**」决定多久检查一次
（缺省每周，可改 6 小时到每月）。**自己导入的词库没有这一项** —— 它们没有稳定上游，青简不去猜。
检查与下载在后台线程做，下载好之后重新装配词库、立刻生效，不用重启。
状态记在数据目录的 `dict-update.tsv`（上次检查时间 + 每本当前装的版本）。

## 置顶 / 后置 / 隐藏一个词（候选窗里的修饰键 + 数字）

> 终端类应用（Warp、iTerm 等）会把 `⌃+数字` 当自己的快捷键（切 pane / tab），输入法收不到。
> 在这些应用里想用「隐藏 / 删候选」，去「偏好设置 → 快捷键」把它们录成别的组合 ——
> `⇧⌃+数字` 这类带两个修饰键的收得到（实测），`⇧⌥`、`⌃⌥` 则可能撞上译词键或应用自己的快捷键。
> 新加的「置顶」是 `⇧+数字`，不含 `⌃`，不受影响。

词库里的词删不掉（它属于词库，也不该因为你一次手滑就消失）。候选窗里对着某一格按修饰键 + 数字时：

| 按键 | 词库里的词 | 你自己学过的词 |
| --- | --- | --- |
| **置顶**（缺省 `Shift` + 数字） | 记成「置顶」：**只在你敲的那个输入串下**排最前 —— `ni` 下钉「你」不影响 `nimen`（那里该出「你们」）。同音字的顺序会随上下文变（`ba` 下有时代 把、有代 吧），想让「吧」在 `ba` 下永远第一就用它。**再按一次恢复** | 同左（只钉那一个输入串，别的输入串照常） |
| **后置**（缺省 `Shift` + `Control` + 数字） | 记成「后置」：还看得见，但从此排在候选最后（`ui` 下的 `UI`、`Ha'h` 下的 `Hahn` 就是它的用处）。**再按一次恢复** | 真的删掉，并清掉学习记录 |
| **隐藏**（缺省 `Control` + 数字） | 记成「隐藏」：不再出现在候选里（`wodge`、`WODGES` 这种） | 同上，真的删掉 |

按键都能在「偏好设置 → 快捷键」里改（「置顶候选」「删除候选」「隐藏候选」三行）。
配置里某个组合与其他动作撞车时，会**回落到缺省并在日志里记一条警告** ——
按了没反应先看日志（`~/Library/Logs/Qingjian/`），别猜。

标过的词都在**「屏蔽词」页**里逐条列出（词 · 状态 + 「恢复」按钮），页顶还有「**恢复全部**」按钮。
标错了不用慌：去那一页点「恢复」就回来了。
设置保存在用户数据目录：`user-sort.tsv`（`词\t偏好`，后置 / 隐藏）与 `user-pins.tsv`
（`输入串\t词`，置顶）。删掉对应那行等于恢复；置顶也可以在同一输入串下再按一次 `⇧+数字` 解开。
